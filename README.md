# Dictionary Project

A modern, responsive dictionary web application built with React and Vite.

The project allows users to search for words, explore definitions and related information, and discover a Word of the Day.

## Features

- Word search with results
- Word definitions and related information
- Word of the Day
- Recent searches
- Light and dark mode
- Responsive design

## Technologies

- React
- Vite
- JavaScript
- CSS
- Dictionary API
- ESLint

## AI-Assisted Development

AI coding tools were used as part of the development process for brainstorming, debugging, code generation, and implementation.

I reviewed and tested the generated changes and made adjustments to integrate them with the project.
